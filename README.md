# 流行之神脚本编辑系统

## 项目概述

流行之神脚本编辑系统是一个基于Streamlit开发的Web应用程序，用于编辑和管理游戏脚本文本。该系统支持多用户协作，提供了文本编辑、查找、预览等功能，并能够实时显示带有控制符的游戏文本的模拟效果。

## 主要功能

### 用户管理
- **用户登录**：支持用户名和密码验证
- **密码修改**：允许用户修改自己的登录密码
- **权限控制**：基于用户权限显示可编辑的文本库
- **登录记录**：自动记录用户最后登录时间

### 文本编辑
- **文本库选择**：用户可以选择有权限的文本库进行编辑
- **文本浏览**：通过滑动条或上下按钮浏览文本条目
- **文本搜索**：支持在原文或译文中向前/向后搜索特定内容
- **实时预览**：编辑时可实时预览带控制符文本的显示效果
- **文本替换**：可以对译文进行批量替换，提高编辑效率

### 特殊功能
- **控制符验证**：自动检查输入文本中的控制符格式是否正确
- **控制符显示切换**：可选择显示原始控制符或处理后的文本

## 安装说明

### 系统要求
- Python 3.7+
- MySQL数据库

### 依赖项安装
```bash
pip install -r requirements.txt
```

主要依赖项：
- streamlit
- mysql-connector-python
- bcrypt

### 配置说明
1. 在`.streamlit/secrets.toml`文件中配置MySQL数据库连接信息：
   ```toml
   [mysql]
   host = "your_mysql_host"
   user = "your_mysql_username"
   password = "your_mysql_password"
   database = "your_mysql_database"
   ```

## 使用指南

### 启动应用
```bash
cd lxzs_editor
streamlit run lxzsedit.py
```

### 基本操作流程
1. **登录系统**：输入用户名和密码
2. **选择文本库**：从有权限的文本库列表中选择要编辑的文本库
3. **编辑文本**：
   - 使用滑动条或上下按钮浏览文本条目
   - 在译文区域编辑文本
   - 实时查看模拟显示效果
   - 点击「保存译文」按钮保存更改
4. **搜索功能**：
   - 在侧边栏输入搜索文本
   - 选择搜索范围（原文或译文）
   - 点击「向前查找」或「向后查找」按钮

### 注意事项
- 编辑文本时需注意控制符的正确使用，系统会自动验证控制符格式
- 「guest」用户无权更新数据，仅供演示使用
- 编辑统计功能仅显示最近10天的数据

## 数据库结构

系统使用以下主要数据表：
- **Users**：存储用户信息，包括用户名、密码和最后登录时间
- **tablelist**：存储可编辑的文本库列表
- **user_table**：存储用户与文本库的权限关联
- **各文本表**：存储具体的文本内容，包括ID、原文(jtext)、译文(ctext)、编辑者和更新时间
